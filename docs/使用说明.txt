========================================
 LeetMentor - 力扣 AI 解题导师(便携版)
========================================

【这是什么】
一个本地学习助手,包含三大功能:

1) 力扣 AI 解题导师
   在力扣(leetcode.cn)做题时,由 AI 给出三层引导式讲解:
     第 1 层 · 思路引导  —— 只给启发,让你自己想
     第 2 层 · 详细步骤  —— 从暴力解法讲到优化和伪代码
     第 3 层 · 参考代码  —— 所选语言的代码 + 逐段讲解
   支持 Python3 / Java / C++ / JavaScript / Go / C# / Rust 等语言随时切换。

2) 学科题划词讲解 + 识图解题
   在任意网页上选中一段文字(数学 / 物理 / 化学题、概念、材料段落),
   会出现小「✨ 讲解」按钮;点开可看讲解,还能在底部输入框连续追问。
   面板里按 Ctrl+V 可直接粘贴截图(或点 📷 选图),AI 会先识别题目再讲解。

3) 学习工作台(浏览器打开 http://127.0.0.1:8765/study)
   - 论文总结:粘贴 arXiv 链接 / 上传 PDF / 粘贴文字,一键生成结构化总结;
     可选「简单分析」(摘要)或「详细分析」(全文,含实验思路、结果表格、启示与反思)
   - 学科题:粘贴题目文字或截图讲解并追问
   - 实验数据:上传 CSV / Excel 或粘贴数据,自动统计 + 绘图 + AI 解读
   - 工具箱:图片→PDF、PDF 合并/拆分/转图片/加密、Office→PDF、PDF→Word 等
     常用文件转换,全部在本机完成、免费

【三步开始使用】
第 1 步:双击 LeetMentorServer.exe
        浏览器会自动打开设置页;填写 DeepSeek API Key(没有的话,
        到 https://platform.deepseek.com 注册创建,充值 10 元够用很久),
        点「保存」,再点「测试连接」确认成功。
        注意:这个黑色窗口要一直开着(Ctrl+C 或关窗口 = 停止服务)。

第 2 步:在你的浏览器(推荐 Edge)安装油猴脚本
        1) 打开 Edge,进入 Microsoft Edge 加载项商店,搜索 "Tampermonkey" 并安装
        2) 安装后,把本文件夹里的 leetcode-mentor.user.js 直接拖进浏览器窗口,
           在弹出的安装页面点「安装」即可
        3) 如工具栏看不到图标,在 edge://extensions 里把它固定到工具栏

第 3 步:打开任意力扣题目页(如 https://leetcode.cn/problems/two-sum/)
        页面右下角出现「✨ AI 讲解」按钮,点击开始学习。

【常见问题】
Q: 点击按钮提示"本地服务未运行"?
A: 确认 LeetMentorServer.exe 的窗口还开着;然后点面板里的「重试」。
   如果改了端口,脚本会自动探测 8765~8769。

Q: 提示"API Key 无效"?
A: 打开 http://127.0.0.1:8765/setup 重新填写 Key 并测试连接。
   注意 Key 区分大小写,前后不要有空格。

Q: 无法连接 DeepSeek / 超时?
A: 检查网络;部分网络环境需要代理才能访问 api.deepseek.com。

Q: 题目读不出来?
A: 刷新页面重试;会员专享题目的完整题面可能无法读取。

Q: 讲解内容保存在哪?会重复收费吗?
A: 同一道题同一层讲解只请求一次,结果缓存在 data\cache.db;
   重复查看不花钱。换语言只会重新请求第 3 层。

Q: 双击 LeetMentorServer.exe 提示「已被组织策略或 Device Guard 阻止」?
A: 这台电脑开启了 Smart App Control(智能应用控制),它只允许运行具有可信签名的
   程序,未签名的 exe 会被拦截。两种解决办法:
   1) 换用源码方式:安装 Python 后,依次运行 scripts\setup.bat 和 scripts\start.bat;
   2) 关闭 Smart App Control:Windows 安全中心 → 应用和浏览器控制 → 智能应用控制
      → 关闭(注意:关闭后需重装系统才能重新开启,请自行权衡)。
   此问题与程序本身无关,在未开启该功能的电脑上可直接双击运行。

【数据与隐私】
- API Key 和缓存都保存在本程序目录下的 data\ 文件夹,不会上传到任何第三方。
- 程序只在本机监听 127.0.0.1,局域网内其他电脑无法访问。
- 题面内容会发送给 DeepSeek 用于生成讲解,除此之外无其他数据外传。
