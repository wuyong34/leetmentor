LeetMentor 解题
💡 微信里使用小提示
微信内置浏览器不允许网页自动读取剪贴板或屏幕,推荐两种最快的用法:
① 截图题目 → 点下面「从相册选图」,选刚截的图 → 出答案
② 长按复制题目文字 → 点「输入 / 粘贴题目」,在大框里长按粘贴 → 自动开始解答
(如果想要"网页一键抓题"书签,请在 Edge 手机版里使用)
📋
从剪贴板解题在任何 App 里复制题目,回到这里一键解答
⌨️
输入 / 粘贴题目手动输入或长按粘贴文字
📷
拍照解题拍摄纸质作业、试卷(图片兜底方案)
🖼️
从相册选图截图或照片
🔖 把「一键抓题」装进浏览器书签(推荐)
装好后,在任何网页上点一下这个书签,就会自动抓取页面上的题目并跳到这里解答,不用拍照也不用复制。

Edge 手机版:① 点下面的「复制书签代码」→ ② Edge 菜单 → 收藏夹 → 添加收藏 → 名称填 一键抓题,地址栏长按粘贴刚才的代码 → 保存 ③ 以后在题目网页的地址栏输入"一键抓题"选中它即可。
📲 添加到手机主屏幕(像 App 一样用)
Edge 手机版:菜单 → 「添加到手机」/「添加到主屏幕」→ 确认。
微信里:把本页链接发给「文件传输助手」,随时点开即用(可再加到浮窗)。
